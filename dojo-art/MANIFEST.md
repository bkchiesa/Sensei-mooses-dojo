# Christiano + Dakota action sprite sheets (raw)

SF2 arcade + 64-bit N64 low-poly sheets for two arcade-ladder bosses.
Each file is one horizontal animation sheet on solid magenta (`#FF00FF`) chroma.
All fighters face **RIGHT**. Closed white gi, barefoot. No Capcom logos/text/HUD.

No process script existed in this checkout, so raw sheets are also copied to the concepts path (not sliced / not written to `finals/fighters/`).

Filename pattern: `dojo-art/work/raw/<id>/raw_<id>_<anim>_sheet.png`

Tokens + panel counts:

| Token | Panels | Layout |
| --- | --- | --- |
| `idle` | 4 | breathing bob |
| `punch` | 4 | chamber / launch / IMPACT / recovery |
| `kick` | 4 | chamber / extend / IMPACT / recovery |
| `jump` | 4 | launch / rise / apex / descent (height reads across panels) |
| `block` | 2 | guard-up / hold |
| `crouch` | 2 | dropping / full crouch |
| `sweep` | 4 | LOW ground sweep chamber / wind-up / IMPACT / recovery |

Total: **14** sheets (2 fighters × 7 anims). All generated; no failures.
