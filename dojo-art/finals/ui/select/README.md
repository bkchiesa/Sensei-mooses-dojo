# PLAYER SELECT UI (Pixel drop-in)

Homage layout (no Capcom IP): large 1P / 2P portraits, **Virginia Lower Peninsula / Hampton Roads** map in the center, `PLAYER SELECT` label, fighter headshot grid along the bottom.

The SF2-style chrome (oval frame, busts, `PLAYER SELECT`, headshot grid) is wired in code. The **map plate is a swap-in**. Landmark dots stay in code on real lon/lat so a B-faithful plate can drop in without moving pips.

Drop finals here. `npm run export-assets` copies them to `web/public/assets/ui/select/` and writes `plate.json` (PNG wins over the SVG placeholder).

| File | Role |
| --- | --- |
| `select_map_plate.png` or `hampton-roads-map.png` | **Locked map plate (C).** Replaces the SVG placeholder. Dots overlay in code. |
| `select_screen.png` | Optional full-screen wash behind live 1P/2P chrome. Portraits on this art are stand-ins. |
| `hampton-roads-map.svg` | Geo-faithful placeholder (same UV as the dots). Regenerated by `web/scripts/render-peninsula-placeholder.mjs`. |
| `select-panel.png` | Optional portrait frame |
| `select-dot.png` | Optional location pip (unused — code draws pips) |

Until finals copy, drop the same filenames in `dojo-art/concepts/ui/select/`. Export copies concepts first; **finals overwrite**.

## Plate contract (must match `web/src/data/peninsula.ts`)

North-up rectangle. **No landmark pips** on the art. Optional painted water / city names are fine.

| | |
| --- | --- |
| Lon | **−76.76** (west) … **−76.28** (east) |
| Lat | **36.955** (south) … **37.30** (north) |
| UV | `u = (lon − lonMin) / 0.48` · `v = 1 − (lat − latMin) / 0.345` |
| Aspect | **1111 × 1000** (or any size with width/height ≈ **1.111**) |
| Projection | Equirectangular, standard parallel **37.13°N** (cosine so 1° lon is not stretched to 1° lat) |

Full image = full bounds. **Do not** letterbox, pad, or bake the oval into the file — the game letterboxes the plate inside the SF2 chrome and clips to the ellipse.

Do **not** include Street Fighter wordmarks, globe, or character likenesses.
